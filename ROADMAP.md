# После 1.0

В исходном релизе завершены перечисленные в CHANGELOG исправления. Следующие направления требуют отдельных инфраструктурных и продуктовых проектов:

- SFU вместо mesh и распределённый call signaling.
- Краткоживущие TURN credentials и проверка связи из разных сетей.
- Native background incoming calls / foreground service Android.
- Quotas, retention policy, malware scanning и консоль модерации.
- Почтовое восстановление аккаунта с подтверждённой идентичностью.
- Аппаратные passkeys и platform associations для нативных оболочек.
- E2EE только как отдельный протокол с независимой проверкой, без обещания такого свойства в 1.0.
- Инсталляторы с вашими сертификатами, Play Store signing, FCM и production deployment tests.
